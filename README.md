## Overview
본 프로그램은 *The Effects of Task Dimensionality, Endpoint Deviation, Throughput Calculation, and Experiment Design on Pointing Measures and Models* (Jacob O. Wobbrock 외), *AutoGain: Gain Function Adaptation with Submovement Efficiency Optimization* (Byungjoo Lee 외)을 참고해 제작되었습니다.

3D 일인칭 환경에서의 마우스 조작이 2D 스크린상에서와 다를 수 있다는 점에 착안하여 3D 일인칭 게임에서의 마우스 동작을 분석하고, AutoGain을 기반으로 3D FPS 버전의 게임 함수 자동 최적화를 시도하였습니다.
